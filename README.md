# 醫護人員 AI 實作課程

用一份 PDF（`114年12月教學活動_去識別化.pdf`），透過打字對話，學會跟 AI 合作：查資料、整理表格、抓錯、寫文件、做簡報。

## 0. 事前準備：請 AI 安裝 uv

上課前先把下面這句話貼給 AI，讓它幫你安裝（Windows 版）：

```
請幫我在這台 Windows 電腦上安裝 uv 套件管理工具，安裝完成後執行 uv --version，確認安裝成功。
```

## 1. 下載教材

```
git clone https://github.com/gemini960114/ai-course-for-clinicians.git
```

不會用 git：在 GitHub 頁面按綠色的 **Code** → **Download ZIP**，下載後解壓縮。

## 2. 用 AI 工具開啟這個資料夾

AI 需要能讀 PDF，並且能產出 Excel、Word、PPT（預設已安裝 `pdf`、`xlsx`、`docx`、`pptx` 四個技能）。

## 3. 第一句話：讓 AI 先讀 PDF

```
@114年12月教學活動_去識別化.pdf 請先閱讀這份 PDF。接下來我的問題都只根據這份 PDF 回答，並註明在第幾頁。不要讀資料夾裡的其他檔案。
```

如果你的工具是用「上傳附件」的方式，就先上傳 PDF，再貼上同一句話（不用加 `@` 那一段）。

> 開新的對話時，要重新做一次這一步。

## 4. 依序練習

打開 `醫護人員AI課程_範例.md`，從單元 0 開始，把每題的提示詞複製給 AI，再對照「標準答案」欄。

**AI 答錯是正常的**，這正是練習的重點：學會追問出處、自己核對。

## 5. 加碼：讓 AI 幫文件存檔

打開 `Git存檔教學_範例.md`，練習用一句話存檔、退回、查看版本。

## 注意事項

- 不要輸入任何真實病人資料。
- AI 的答案一定要回 PDF 核對，尤其是表格。
